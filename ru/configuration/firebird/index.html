    Настройка Firebird¶

    Версия документа: 1.0

    1. Назначение¶

    Документ описывает общие требования к Firebird и настройку подключений портала АСУ МКР к базам данных.

    Портал использует две базы:

    Подключение Назначение
    BD Основная база данных АСУ МКР
    BDD Дополнительная база данных

    2. Требования¶

    Рекомендуемая версия:

    Firebird 3.0.x

    Firebird может быть установлен:

    • на том же сервере, что и портал;
    • на отдельном сервере в локальной сети;
    • на выделенном сервере баз данных.

    3. Установка¶

    Установите Firebird 3.0.x средствами операционной системы либо официальным пакетом Firebird.

    На Debian и Ubuntu названия пакетов зависят от доступного репозитория. Перед установкой убедитесь, что устанавливается именно совместимая версия.

    Проверьте состояние службы:

    sudo systemctl status firebird3.0

    Если имя службы отличается, найдите его:

    systemctl list-units --type=service | grep -i firebird

    4. Размещение баз данных¶

    Файлы баз данных рекомендуется хранить вне публичных каталогов веб-сервера.

    Пример:

    /var/lib/firebird/data/BD.FDB
/var/lib/firebird/data/BDD.FDB

    Важно

    Нельзя размещать файлы баз данных в каталогах frontend/web, backend/web или api/web.

    5. Права доступа¶

    Пользователь службы Firebird должен иметь права чтения и записи к файлам баз данных и содержащему их каталогу.

    Проверьте владельца и права:

    ls -la /var/lib/firebird/data

    Не выдавайте файлам баз данных права 777.

    6. Сетевой доступ¶

    Если Firebird находится на отдельном сервере:

    1. Разрешите подключения Firebird только с адреса сервера портала.
    2. Проверьте межсетевой экран.
    3. Не публикуйте порт Firebird в Интернет без необходимости.
    4. Используйте защищенную сеть или VPN.

    Стандартный порт Firebird:

    3050/TCP

    7. Проверка подключения¶

    Для проверки можно использовать isql из комплекта Firebird.

    Пример локального подключения:

    isql-fb /var/lib/firebird/data/BD.FDB -user SYSDBA -password '<пароль>'

    Пример сетевого подключения:

    isql-fb <сервер>:/var/lib/firebird/data/BD.FDB -user <пользователь> -password '<пароль>'

    После подключения выполните:

    SHOW DATABASE;

    Для выхода:

    QUIT;

    8. Настройка портала¶

    Подключения настраиваются в файле:

    common/config/main-local.php

    Для каждой базы необходимо указать:

    • адрес сервера или путь к файлу;
    • имя пользователя;
    • пароль;
    • используемую кодировку;
    • параметры подключения PDO Firebird.

    Пример структуры настройки:

    'db' => [
    'class' => yii\db\Connection::class,
    'dsn' => 'firebird:dbname=<сервер>:<путь_к_BD>;charset=UTF8',
    'username' => '<пользователь>',
    'password' => '<пароль>',
],

    Фактические имена компонентов и структура конфигурации должны соответствовать конфигурации проекта.

    Важно

    Не копируйте пример без проверки. Используйте реальные имена компонентов BD и BDD, принятые в проекте.

    9. Безопасность¶

    Рекомендуется:

    • создать отдельного пользователя Firebird для портала;
    • не использовать пароль по умолчанию;
    • ограничить сетевой доступ;
    • регулярно создавать резервные копии;
    • хранить резервные копии отдельно от рабочего сервера;
    • не добавлять пароли в публичный репозиторий.

    10. Резервное копирование¶

    Для резервного копирования используйте штатные инструменты Firebird, например gbak.

    Пример:

    gbak -b -user <пользователь> -password '<пароль>'     /var/lib/firebird/data/BD.FDB     /backup/BD.fbk

    Перед автоматизацией резервного копирования проверьте восстановление на тестовом сервере.

    11. Типичные ошибки¶

    Could not find driver¶

    PHP не видит драйвер Firebird.

    Проверьте:

    php -m | grep -i firebird

    В списке должен присутствовать pdo_firebird.

    Unable to complete network request¶

    Проверьте:

    • адрес сервера;
    • порт 3050;
    • работу службы Firebird;
    • межсетевой экран;
    • путь к файлу базы данных.

    Permission denied¶

    Проверьте права пользователя службы Firebird к файлу базы данных.
