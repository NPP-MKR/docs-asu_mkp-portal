# Локализация документации

## Структура

Документация использует плагин `mkdocs-static-i18n` и структуру каталогов по языкам:

```text
docs/
├── assets/
├── ru/
└── uk/
```

Русский язык является основным. Его страницы публикуются в корне сайта.

Украинские страницы публикуются в каталоге `/uk/`.

## Добавление украинского перевода

Для перевода русской страницы:

```text
docs/ru/installation/install.md
```

создайте файл с таким же относительным путем:

```text
docs/uk/installation/install.md
```

Названия каталогов и файлов должны совпадать. Переводится только содержимое Markdown-файла.

## Непереведенные страницы

В конфигурации включено:

```yaml
fallback_to_default: true
```

Поэтому при отсутствии украинского файла будет показана русская версия страницы.

## Ссылки между страницами

Используйте относительные ссылки без указания языкового каталога:

```markdown
[Установка портала](installation/install.md)
```

Плагин сам выберет страницу текущего языка.

## Навигация

Названия разделов меню переводятся через параметр `nav_translations` в `mkdocs.yml`.

## Проверка

Запустите локальный сервер:

```bash
mkdocs serve
```

Проверьте:

- русскую версию по адресу `/`;
- украинскую версию по адресу `/uk/`;
- переключатель языка;
- ссылки между страницами;
- поиск.
