# Частые вопросы и типичные ошибки

Версия документа: 1.0

## 1. PHP не найден

Ошибка:

```text
php: command not found
```

Проверьте установку PHP:

```bash
php -v
```

Если PHP установлен, но команда недоступна, проверьте `PATH`.

## 2. Composer не найден

Ошибка:

```text
composer: command not found
```

Проверьте:

```bash
composer --version
```

Убедитесь, что Composer установлен глобально или запускайте его через полный путь.

## 3. Не найден драйвер Firebird

Ошибка:

```text
could not find driver
```

Проверьте:

```bash
php -m | grep -i firebird
```

Установите расширение `pdo_firebird` или соответствующий пакет `interbase`.

## 4. Permission denied (publickey)

Проверьте:

- регистрацию публичного ключа;
- файл `~/.ssh/config`;
- путь `IdentityFile`;
- доступ к выбранному репозиторию.

Подробно: [Получение исходного кода](../installation/repository.md).

## 5. Could not resolve hostname github-mkp

Псевдоним `github-mkp` не найден.

Проверьте запись:

```text
Host github-mkp
    HostName github.com
```

в файле `~/.ssh/config`.

## 6. Ошибка 403

Проверьте:

- корневой каталог виртуального хоста;
- права доступа;
- настройки `<Directory>` в Apache;
- настройки `root` в Nginx.

## 7. Ошибка 404 на внутренних страницах

Для Apache проверьте `mod_rewrite` и `AllowOverride`.

Для Nginx проверьте `try_files`.

## 8. Ошибка 500

Проверьте:

- журнал приложения;
- журнал веб-сервера;
- журнал PHP;
- конфигурацию `main-local.php`;
- доступность баз данных;
- наличие PHP-расширений.

## 9. Ошибка 502 в Nginx

Проверьте:

- состояние PHP-FPM;
- путь к сокету;
- права доступа к сокету.

## 10. Не загружаются файлы

Проверьте:

- настройки хранилища;
- доступность каталога;
- ограничения `upload_max_filesize`;
- ограничения `post_max_size`;
- свободное место.

## 11. Сертификат не продлевается

Выполните:

```bash
sudo certbot renew --dry-run
```

Проверьте DNS, порт 80 и таймер Certbot.

## 12. После обновления отображается старая версия

Очистите кэш приложения:

```bash
php yii cache/flush-all
```

Затем очистите кэш браузера.

## 13. Где искать журналы

Смотрите:

- `frontend/runtime/logs`;
- `backend/runtime/logs`;
- журналы API;
- `/var/log/apache2`;
- `/var/log/nginx`;
- системный журнал.

Фактические пути зависят от конфигурации проекта.
