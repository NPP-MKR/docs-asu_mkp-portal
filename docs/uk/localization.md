# Локалізація документації

## Структура

Документація використовує `mkdocs-static-i18n`:

```text
docs/
├── assets/
├── uk/
└── ru/
```

Українська мова є основною та публікується в корені сайту. Російська версія публікується в каталозі `/ru/`.

## Відповідність сторінок

Мовні версії повинні мати однаковий відносний шлях:

```text
docs/uk/installation/install.md
docs/ru/installation/install.md
```

Назви каталогів і файлів не перекладаються, перекладається лише вміст Markdown.

## Неперекладені сторінки

Увімкнено:

```yaml
fallback_to_default: true
```

Якщо російська сторінка відсутня, буде показано основну українську версію.

## Посилання

Використовуйте відносні посилання без мовного каталогу:

```markdown
[Установлення порталу](installation/install.md)
```

## Перевірка

```bash
mkdocs serve
```

Перевірте українську версію в `/`, російську в `/ru/`, перемикач мови, пошук і внутрішні посилання.
