# Отримання вихідного коду

Версія документа: 1.0

## 1. Призначення

Документ описує вибір версії порталу, створення SSH-ключа, отримання доступу та клонування репозиторію.

## 2. Версії порталу

| Версія | Статус |
|---|---|
| **v2** | Актуальна стабільна версія, що використовується в експлуатації |
| **v3** | Нова версія порталу, рекомендована для нових установлень |

### Репозиторії

| Версія | Репозиторій |
|---|---|
| v2 | `git@github-mkp:NPP-MKR/mkp-portaloriginal.git` |
| v3 | `git@github-mkp:NPP-MKR/mkp-portaloriginal-v3.git` |

## 3. Створення SSH-ключа

Створіть окремий ключ `id_mkp`:

```bash
ssh-keygen -t ed25519 -C "your-email@example.com" -f ~/.ssh/id_mkp
```

Буде створено:

| Файл | Призначення |
|---|---|
| `~/.ssh/id_mkp` | Приватний ключ |
| `~/.ssh/id_mkp.pub` | Відкритий ключ |

!!! danger "Важливо"
    Приватний ключ `id_mkp` не можна нікому передавати.

## 4. Надсилання відкритого ключа

Надішліть вміст файла:

```text
~/.ssh/id_mkp.pub
```

на адресу:

**info@mkr.org.ua**

У листі вкажіть:

- організацію;
- П.І.Б.;
- посаду;
- контактний e-mail;
- проєкт «АСУ МКР»;
- потрібну версію порталу.

Після реєстрації ключа адміністратор повідомить про надання доступу.

## 5. Налаштування SSH

Відкрийте або створіть файл:

```text
~/.ssh/config
```

Додайте:

```text
Host github-mkp
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_mkp
    IdentitiesOnly yes
```

## 6. Перевірка підключення

Виконайте:

```bash
ssh -T git@github-mkp
```

Якщо з'являється помилка:

```text
Could not resolve hostname github-mkp
```

перевірте файл `~/.ssh/config` і запис `Host github-mkp`.

## 7. Вибір каталогу

Для Linux зазвичай використовується `/var/www`:

```bash
cd /var/www
```

## 8. Клонування v2

```bash
git clone git@github-mkp:NPP-MKR/mkp-portaloriginal.git mkp
```

## 9. Клонування v3

```bash
git clone git@github-mkp:NPP-MKR/mkp-portaloriginal-v3.git mkp
```

!!! note "Примітка"
    Для нових установлень рекомендовано v3. Якщо організація вже використовує v2, вибір версії слід погодити з фахівцями супроводу.

## 10. Каталог порталу

Після клонування перейдіть до проєкту:

```bash
cd /var/www/mkp
```

У документації цей шлях позначається як:

```text
<каталог_порталу>
```

## 11. Оновлення локальної копії

```bash
cd <каталог_порталу>
git pull
```

Повний порядок оновлення наведено в [інструкції з установлення](install.md#12-оновлення-порталу).

## 12. Типові помилки

### Permission denied (publickey)

Перевірте реєстрацію відкритого ключа, `IdentityFile` і права доступу до репозиторію.

### Could not resolve hostname github-mkp

Перевірте запис `Host github-mkp` у `~/.ssh/config`.

### Repository not found

Перевірте адресу репозиторію та надані права доступу.
