# Налаштування файлового сховища

Версія документа: 1.0

## 1. Призначення

Документ описує зберігання файлів порталу АСУ МКР.

## 2. Налаштування за замовчуванням

Портал використовує локальну файлову систему:

| Сховище | Каталог |
|---|---|
| `fs` | `@webroot/documents` |
| `storage` | `@frontend/web` |

Для стандартного встановлення рекомендовано залишити ці налаштування без змін.

## 3. Локальна файлова система

Локальне сховище підходить, якщо портал працює на одному сервері та налаштовано резервне копіювання.

Каталоги й права створюються під час виконання:

```bash
php init --env=Production
```

!!! warning "Важливо"
    Не змінюйте права вручну без необхідності.

## 4. Зовнішні сховища

Підтримуються:

- AWS S3;
- S3-compatible;
- FTP;
- SFTP;
- WebDAV.

Зовнішнє сховище доцільне для кількох серверів застосунку, масштабування або окремого зберігання документів.

## 5. AWS S3 і S3-compatible

Зазвичай потрібні:

| Параметр | Призначення |
|---|---|
| Endpoint | Адреса сервісу |
| Region | Регіон |
| Bucket | Контейнер |
| Access key | Ідентифікатор доступу |
| Secret key | Секретний ключ |

!!! danger "Важливо"
    Не зберігайте секретні ключі в Git.

## 6. FTP і SFTP

Для FTP потрібні адреса, порт, користувач, пароль і віддалений каталог.

Замість звичайного FTP рекомендовано використовувати SFTP, що працює через SSH.

## 7. WebDAV

Потрібні URL, користувач, пароль, кореневий каталог і чинний HTTPS-сертифікат.

## 8. Налаштування порталу

Параметри зберігання зазвичай розміщуються в:

```text
common/config/main-local.php
```

Фактична структура залежить від версії порталу та адаптера сховища.

## 9. Перевірка

Після налаштування:

1. Завантажте тестовий файл.
2. Перевірте його появу в сховищі.
3. Відкрийте або завантажте файл через портал.
4. Перевірте журнали.
5. Видаліть тестовий файл штатними засобами.

## 10. Резервне копіювання

Локальне сховище включіть до резервного копіювання сервера.

Для зовнішніх сховищ перевірте версіонування, реплікацію, строк зберігання видалених файлів і процедуру відновлення.

## 11. Типові помилки

### Файл завантажується, але не відкривається

Перевірте шлях, права доступу, URL і доступ вебсервера.

### Помилка авторизації

Перевірте облікові дані та дозволи.

### Помилка сертифіката

Перевірте SSL-ланцюжок і системне сховище довірених сертифікатів.
